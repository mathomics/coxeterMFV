# Yeast9 solver comparison figure

The four panels are FBA, pFBA, CycleFreeFlux, and ordinary FVA with pFBA point values. The Coxeter map panels use the light theme and show the same part of the map, the mitochondrion and the cytoplasm beside it, where the solutions differ. Each names five reactions with their flux in that solution: the second aconitase step (r_0280), mitochondrial NAD-dependent isocitrate dehydrogenase (r_0658), cytosolic NADP-dependent isocitrate dehydrogenase (r_0659), and the external (r_0770) and internal (r_0773) NADH dehydrogenases of the inner mitochondrial membrane, which oxidize cytosolic and matrix NADH. The map's own compartment tags, which the crop would cut, are hidden, and the figure names the two compartments itself. pFVA is omitted from the figure. Methods, statistics and interpretation belong in the caption, which is in the manuscript.

All figure text uses Arial.

The earlier pFVA analysis files are retained as analysis records and are not used in this figure.

## Drawing

The figure drawing adds three reactions to the older 115-reaction manuscript map, all already present in the complete model: direct citrate hydroxymutase (r_4262) and mitochondrial NADP-dependent isocitrate dehydrogenase (r_2131), taken from the repository's current curated map, and cytosolic NADP-dependent isocitrate dehydrogenase (r_0659), which FBA and CycleFreeFlux use instead of the mitochondrial NAD-dependent enzyme. The source model and its bounds were not changed. r_4262 and r_2131 are drawn because pFBA converts citrate to isocitrate through r_4262 while the two-step aconitase route r_0302/r_0280 is inactive. FBA can additionally route TCA-related flux through cytosolic reactions and mitochondrial transporters, so a mitochondrial ring need not carry uniform flux.

Ten additional model reactions complete representative active amino acid alternatives in the drawing: r_0471, r_0476, r_0468, r_0473, r_1887, r_0957, r_0029, r_0699, r_1596 and r_0663. Their geometry, and that of r_0659, is generated by `figure_amino_acids.mjs` from the original model stoichiometry. Original map geometry is retained.

## Amino acid diagnosis

All 20 standard amino acid exchanges have lower bound 0 and upper bound 1000. Their stoichiometric coefficient is −1, so uptake would require a negative flux and is blocked. None imports in any of the three solutions; glycine is secreted at about 0.006609 mmol gDW⁻¹ h⁻¹. Glucose is the only active organic input. All 20 cytosolic aminoacyl-tRNA charging fluxes are positive, consistent with synthesis to support protein production.

Some apparently inactive pathways were active but much smaller than respiratory fluxes. Others were inactive alternatives to the route actually used. In pFBA, representative synthesis fluxes are:

| Route | Model reactions | Flux magnitude (mmol gDW⁻¹ h⁻¹) |
|---|---|---:|
| Glutamate synthesis | r_0471 | 0.448583 |
| Glutamine synthesis | r_0476 | 0.084746 |
| Proline synthesis | r_0468, r_0473, r_1887, r_0957 | 0.014584 |
| Cytosolic leucine terminal steps | r_0029, r_0699 | 0.029401 |
| Isoleucine precursor export and cytosolic transamination | r_1596, r_0663 | 0.021531 |

The existing mitochondrial terminal transaminases r_0664 and r_0700 are inactive here, while the cytosolic alternatives synthesize isoleucine and leucine. The mapped mitochondrial proline oxidase r_0940 and P5C dehydrogenase r_0012 are degradative, so their inactivity does not indicate a failure to synthesize proline. Peroxisomal fatty acid oxidation is also inactive in this glucose condition. No pathway was activated by imposing an arbitrary lower bound.

## TCA diagnosis

The stoichiometric sum of r_0302 and r_0280 is exactly r_4262: the cis-aconitate and water terms cancel. Minimizing the sum of absolute flux favors the one-step representation over the equivalent two-step representation when its bounds allow the same conversion. Here it is well below its upper bound.

| Reaction | FBA | pFBA | CycleFreeFlux |
|---|---:|---:|---:|
| r_0302, citrate to cis-aconitate | -1000 | 0 | 0 |
| r_0280, cis-aconitate to isocitrate | -1000 | 0 | 0 |
| r_4262, direct citrate to isocitrate | 0.772134 | 0.633850 | 0.078078 |
| r_0658, mitochondrial NAD-dependent IDH | 0 | 0.555773 | 0 |
| r_2131, mitochondrial NADP-dependent IDH | 0.078078 | 0.078078 | 0.078078 |

The older manuscript caption already documented the omitted direct aconitase reaction. The current curated map in `models/maps/yeast9-9-1-1.json` includes both additions, so its existing reaction geometry is reused here. This composition is Figure 2 of the manuscript, with its caption rewritten in the manuscript's style.

## Validation and reproduction

Coxeter and COBRApy ordinary-FVA endpoints differ by at most 7.7 × 10⁻⁵ mmol gDW⁻¹ h⁻¹ across 256 endpoints in this run. The validation JSON records the individual errors. Tiny residual values near zero should not receive a biological interpretation. Activity counts in the data use |flux| > 10⁻⁶, giving 74, 71 and 70 mapped active reactions for FBA, pFBA and CycleFreeFlux.

From the repository root:

```text
node paper/yeast9/solver_comparison.mjs
python paper/yeast9/verify_solver_comparison.py
python paper/yeast9/compose_solver_figure.py
```

The JavaScript analysis reuses existing FVA ranges only when the complete model hash, objective fraction and solver identity match. Remove `comparison.json` before running to recompute every FVA endpoint. The model, original manuscript drawing and current curated drawing hashes are recorded in the output. No application dependency was added.
