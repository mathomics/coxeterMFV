# Security

Security fixes are prepared for the latest published release. Older research snapshots remain available for reproducibility; they should not be assumed to receive backported fixes.

If GitHub private vulnerability reporting is enabled, use the repository's **Security > Advisories > Report a vulnerability** action. Describe the affected version, impact and reproduction steps without including unrelated private data.

If that action is unavailable, open a public issue asking the maintainers to establish a private reporting channel. Do not include exploit details or sensitive files in that request. The public maintainer contact and private reporting configuration must be confirmed before publication; see [the publication checklist](docs/PUBLICATION.md).
